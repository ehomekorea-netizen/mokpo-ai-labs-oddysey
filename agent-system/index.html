Introduction

0. 왜 지금 '환경 세팅'인가

같은 AI를 쓰는데 어떤 사람은 하루 업무가 사라지고, 어떤 사람은 여전히 복사-붙여넣기에 하루를 씁니다. 차이는 모델이 아니라 모델이 일할 수 있는 환경입니다. 이 문서는 유튜브 영상 「나만의 AI 업무 시스템 4단계 구축법」의 내용을 초보자도 따라올 수 있게 재구성한 교안입니다.

💡

핵심 문제의식

클로드 오퍬스 5.5 등 모델 성능이 비약적으로 좋아졌는데도 일이 줄어들지 않는 이유는, AI에게 "일할 환경"을 아직 만들어 주지 않았기 때문입니다. 데이터와 작업 공간 세팅이 먼저 선행되어야 AI가 진짜 내 손발처럼 움직입니다.

영상 속 작가님의 화면에는 모든 지식·자동화가 하나의 대시보드에 모여 있습니다. 유튜브·뉴스레터 채널 현황, 메일함, 클릭 한 번으로 실행되는 스킬(예: 사업자 정보 기반 견적서를 HWP로 생성), 매일 정해진 시간에 도는 예약 작업(루틴), 그리고 지식 전체의 연결망을 보여 주는 세컨드 브레인까지. 이 대시보드는 결과물일 뿐이고, 그 밑에 오늘 우리가 배울 4단계 배경 작업이 깔려 있습니다.

4. 익스텐션외부 도구(Gmail·드라이브 등)와 연결손과 발AI가 말만 하고 일은 내가 함
Step 1 · Skill

1 스킬 (Skill) — AI 업무 단축키

💡

왜 필요한가?

같은 작업을 2번 이상 시켰다면 무조건 스킬로 전환합니다. 스킬은 "이 업무를 이렇게 해 줘"라는 절차를 파일로 저장해 둔 것으로, 대화창에서 한 마디만 꺼내면 언제든 같은 품질로 재실행됩니다.

🧰

무엇을 준비해야 하는가?

클로드 데스크탑 앱(스킬 메뉴가 내장되어 있음) 하나면 충분합니다. 코딩을 몰라도 됩니다 — 스킬 파일은 결국 마크다운(지시문)과 참고자료 묶음입니다.

레벨별 실행 방법

초급

기본 탑재 '스킬 크리에이터' 활용

  • 클로드 데스크탑 → 사용자 지정 → 스킬 메뉴에서 앤트로픽 기본 스킬 확인
  • 가장 인기 있는 것은 스킬 크리에이터: "원하는 스킬"을 말만 하면 알아서 만들어 줌
  • 채팅창에 "스킬 크리에이터 사용해서 ~해 줘"라고 하면 자동 발동
  • 예시: 트위터에서 발견한 "PC 알아서 고쳐 주는" 프롬프트 전문을 통째로 붙여넣고 "이 프롬프트 전체를 스킬로 만들어 줘" → 이후 "맥 PC 점검해 줘" 한마디로 실행
중급

참고자료가 결합된 다중 파일 스킬

  • SKILL.md(절차 지시문)에 디자인 가이드 style.md, HTML 템플릿, 코드 스니펫 등 참고 파일들을 함께 묶기
  • 스킬 실행 시 AI가 필요한 파일을 스스로 읽고 적용 → 결과물 품질이 "내 브랜드"로 고정됨
  • 예: 썸네일 제작 스킬 = 작성 규칙 + 폰트 규격 + 예전 잘 만든 썸네일 샘플 3장
고급

스킬을 개선하는 메타 스킬

  • 스킬 자체를 업데이트/개선하는 스킬을 또 만듭니다
  • 대화 로그를 읽고 "이 스킬에서 아쉬웠던 점과 개선점을 정리해 스킬 파일을 고쳐 줘"로 운영
  • 스킬이 쓰일수록 스스로 다듬어지는 자기 진화형 단축키 완성
🚀

어떻게 실행하는가? (따라하기)

아래 프롬프트를 클로드 데스크탑 채팅창에 붙여넣어 보세요. 스킬 크리에이터가 자동으로 발동됩니다.

프롬프트 · 초급 — 스킬 만들기 요청
스킬 크리에이터를 사용해서 "매주 월요일 나의 이번 주 강의 일정을 표로 정리해 주는 스킬"을 만들어 줘.
내가 자주 하는 요청 패턴을 참고해서, 다음에 "이번 주 일정 정리해 줘"라고만 말해도
바로 실행되도록 만들어 줘.
프롬프트 · 중급 — 참고자료 결합 스킬
내 문서 폴더의 '브랜드 가이드'와 '지난 견적서 샘플'을 참고자료로 사용해서
견적서 생성 스킬을 다시 만들어 줘. SKILL.md에는 절차를 정리하고,
style.md에는 견적서 디자인 규칙(폰트, 표 형식, 사업자 정보 위치)을 담아 줘.
프롬프트 · 고급 — 스킬을 고치는 메타 스킬
방금 우리 대화 전체 로그를 읽고, "견적서 생성 스킬"이 잘 작동한 부분과 아쉬웠던 부분을
개선점 목록으로 정리해 줘. 그리고 그 개선점을 바로 스킬 파일(SKILL.md)에 반영해서
업데이트된 버전으로 저장해 줘.
Step 2 · Second Brain

2 세컨드 브레인 — 지식·맥락 관리

💡

왜 필요한가?

AI가 내 업무 맥락을 파악하고 필요한 파일을 스스로 찾아 일하게 만드는 구조입니다. 세컨드 브레인이 있으면 스킬의 결과물 품질도 달라집니다 — 스킬이 아무리 좋아도 "나에 대한 지식"이 없으면 평균적인 결과밖에 못 냅니다.

🧰

무엇을 준비해야 하는가?

작업 전용 폴더 하나(예: 클라우드 동기화 폴더)와 텍스트 에디터면 됩니다. 코딩은 필요 없습니다.

레벨별 실행 방법

초급

작업 폴더 + 기본 헌법 파일

  • AI에게 맡길 업무를 위한 전용 작업 폴더를 만든다
  • 그 안에 agent.md(또는 claude.md) 지침 파일을 만들어 항상 준수할 기본 헌법을 적는다 — 말투, 보고 형식, 하지 말아야 할 일
  • AI는 작업 시작 시 이 파일을 먼저 읽는다
중급

길잡이 파일 (Index · 나무위키 형태)

  • 단순 폴더 정리를 넘어, 업무 분야별(콘텐츠·개발·운영 등)로 어떤 문서가 어디 있는지 안내하는 네비게이션 허브를 만든다
  • "콘텐츠 관련 일이면 → contents/ 폴더와 content-index.md를 먼저 읽어라" 같은 라우팅 규칙을 헌법 파일에 추가
  • AI가 스스로 필요한 파일을 찾아 읽고 일한다
고급

나만의 지식 탐색기 대시보드

  • 세컨드 브레인 전체를 보는 웹앱 대시보드를 직접 만든다
  • 폴더 계층 뷰, 문서 간 연결망 시각화, 클릭하면 파일 내용 미리보기
  • 영상 속 대시보드의 "가운데 지구본"이 바로 이것 — 지식 전체의 연결을 한눈에 확인하고 바로 검색
🚀

어떻게 실행하는가? (따라하기)

작업 폴더의 agent.md에 이렇게 시작해 보세요. AI에게 노트북을 사 주는 첫 월급 명세서라고 생각하면 됩니다.

예시 · 초급 — agent.md 기본 헌법
# 나의 AI 작업 규칙 (agent.md)

## 나에 대해
- 프리랜서 AI 강사 / 지역 커뮤니티 운영자
- 문서 톤: 담백하고 간결하게, 과장 없이

## 항상 지킬 것
1. 작업 시작 전 이 폴더의 index.md를 먼저 읽을 것
2. 결과물은 항상 'results/' 폴더에 저장할 것
3. 원본 파일은 절대 수정하지 말고 복사본을 만들 것

## 절 하지 말 것
- 내가 확인 전에는 외부로 아무것도 보내지 않는다
예시 · 중급 — index.md (길잡이 파일)
# 지식 탐색기 (index.md) — 이 폴더의 나무위키

- contents/   : 유튜브 대본, 뉴스레터, 썸네일 규칙 → 먼저 contents/index.md 읽기
- lectures/   : 강의 자료, 계약서, 정산 내역 → 강의 관련 질문은 lectures/ 먼저
- clients/    : 거래처별 메모, 미팅 로그
- assets/     : 로고, 폰트, 자주 쓰는 이미지

라우팅 규칙: 어느 폴더인지 모르겠으면 위 목록에서 키워드로 검색하고,
그래도 없으면 나에게 물어본 뒤 이 index.md에 새 항목을 추가한다.
Step 3 · Routine

3 루틴 (Routine) — 24시간 꺼지지 않는 자동화

💡

왜 필요한가?

스킬이 단축키라면, 루틴은 "정해진 시간(예: 오전 9시)에 그 단축키를 대신 눌러라"고 시키는 스케줄링입니다. 내가 잊어도, 자고 있어도, 시스템은 돌아갑니다. 여기서 진짜 '자동화'가 시작됩니다.

🧰

무엇을 준비해야 하는가?

먼저 1~2단계(스킬 + 세컨드 브레인)가 있어야 합니다. 루틴은 결국 "정해진 시간에 스킬을 실행하라"는 명령이기 때문입니다.

레벨별 실행 방법

초급

클로드 데스크탑 '예약된 작업'

  • 클로드 데스크탑에 내장된 Scheduled Tasks(예약된 작업) 기능 사용
  • 원하는 시간과 반복 주기를 정해 스킬/작업을 등록
  • 단점: 로컬 PC가 켜져 있어야만 작동 — 노트북을 닫으면 멈춤
중급

24시간 무중단 환경 — 2가지 방법

  • 방법 A · 클라우드 가상 컴퓨터(VPS) 대여 후 그 안에서 AI 상시 구동 — 전기료 걱정 없이 24시간 가동
  • 방법 B · 집의 남는 PC(윈도우/미니PC)에 오픈소스 AI(Hermes, OpenClon 등) 상시 가동
  • 방법 B에는 Syncthing(싱크씽)을 곁들여 메인 PC와 세컨드 브레인 파일을 실시간 동기화
  • 월 구독료 대신 전기 한 달 요금으로 자동화를 돌리는 셈
고급

완전 클라우드 네이티브 매니지드 에이전트

  • 직접 서버를 꾸리지 않고, 벤더가 운영하는 Managed Agent 환경에 루틴을 올리는 시대로 이동 중
  • PC를 켜둘 필요조차 없어지는, 에이전트 자동화의 다음 단계 전망
🚀

Step 4 · Extension (+)

4 익스텐션 (+) — 외부 도구와 손발 연결

💡

왜 필요한가?

앞의 3단계로 AI는 머리를 갖췄습니다. 그러나 실제 업무는 브라우저 조작, Gmail 조회, 파일 저장처럼 바깥세상의 손발이 필요합니다. 익스텐션은 AI를 세상에 연결하는 마지막 단계입니다.

🧰

무엇을 준비해야 하는가?

쓰고 있는 구글 계정(Gmail, Drive)이면 초급은 바로 시작할 수 있습니다. 중급 이상은 연결하려는 서비스의 API 정보가 있으면 좋습니다.

레벨별 실행 방법

초급

기본 커넥터 원클릭 연동

  • 클로드 데스크탑의 기본 커넥터로 Google Drive, Gmail 등을 클릭 몇 번으로 연결
  • 연결 즉시 "내 드라이브에서 ~ 찾아 줘", "메일 요약해 줘"가 가능해짐
중급

커스텀 확장 연결 (MCP → CLI → REST API)

  • 연결 확장 순서는 정해져 있습니다: MCP(표준 연결 규격) → CLI(명령줄 도구) → REST API(직접 호출)
  • 기본 커넥터에 없는 서비스는 이 순서로 붙입니다
  • 커넥터 자동 탐색 스킬을 만들어 두면, 새 서비스를 어떻게 연결할지 AI가 스스로 찾아 안내합니다
고급

맞춤 커넥터·전용 웹앱 직접 제작

  • 내 업무에 딱 맞는 자체 마크다운 뷰어, 에셋(자료) 라이브러리 웹앱 등을 직접 만들어 연결
  • 영상 속 대시보드의 캘린더 위젯·이미지/영상 라이브러리가 이 단계의 산물
🚀

어떻게 실행하는가? (따라하기)

가장 흔한 첫 연결인 Gmail·드라이브부터 확인해 보세요.

프롬프트 · 초급 — 커넥터 연결 확인
내 Google Drive와 Gmail 커넥터가 연결되어 있는지 확인해 줘.
연결되어 있다면, 최근 7일간 받은 메일 중 답장이 필요한 것만 골라
한 줄 요약 목록으로 보여 줘.
프롬프트 · 중급 — 커넥터 자동 탐색 스킬
"커넥터 탐색기"라는 스킬을 만들어 줘. 내가 연결하고 싶은 외부 서비스 이름을 말하면,
그 서비스를 MCP → CLI → REST API 순서로 연결하는 가장 쉬운 방법을 찾아
단계별 안내문을 만들어 주는 스킬이도록.
Appendix A

부록 A. 초보자 자가 진단 — 나는 지금 몇 단계?

아래 항목 중 해당하는 것이 많을수록 AI 환경 세팅이 덜 된 상태입니다. 각 진단 바로 옆의 처방전을 확인하세요.

진단 항목해당한다면
비슷한 프롬프트를 매번 새로 작성한다→ 1단계 스킬부터 시작
AI에게 매번 내 상황을 처음부터 설명한다→ 2단계 세컨드 브레인의 agent.md 만들기
AI가 내 파일을 스스로 찾지 못한다→ 2단계 길잡이 파일(index) 구축
PC를 꺼 두면 자동화가 멈춘다→ 3단계 루틴의 VPS/보조 PC 검토
AI가 결국 "복사해서 나 대신 붙여넣는" 것도 못 한다→ 4단계 익스텐션 커넥터 연결
Appendix B

부록 B. 단계별 실천 체크리스트

위에서부터 순서대로 체크해 나가면 그대로 SSR+ 시스템이 완성됩니다. 체크박스는 클릭할 수 있습니다.

🌱 1주차 — 스킬 (Skill)

🧠 2주차 — 세컨드 브레인 (Second Brain)

⏰ 3주차 — 루틴 (Routine)

🤝 4주차 — 익스텐션 (Extension)

🏁

마무리 — "그럼 인간은 뭘 하지?"

스킬은 만들되, 무엇을 만들지 결정하는 것은 사람입니다. 4단계 세팅이 끝나면 일은 줄고, 남은 시간에 우리는 더 나은 질문과 더 나은 판단을 하게 됩니다. 오늘 1단계 스킬 한 개부터 시작해 보세요.
